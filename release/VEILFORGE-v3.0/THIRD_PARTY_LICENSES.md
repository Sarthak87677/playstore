# Third-Party Licences and Asset Provenance

## Summary

VEILFORGE ships **one** third-party component: the Godot Engine runtime, which
is statically linked into the executable. Everything else in the game — every
mesh, texture, material, shader, sound effect, ambience bed, musical instrument,
piece of concept art, and all text — is generated by the game's own code at
runtime or written for this project.

There are no asset packs, no sample libraries, no font files, no stock images,
no model downloads, and no code dependencies beyond the engine.

## Assets created for this project

Every item below is original work produced for VEILFORGE and is covered by the
project's own licence.

| Category | How it is produced | Where |
| --- | --- | --- |
| Meshes | Generated at runtime from noise, trigonometry and `SurfaceTool` | `project/autoload/ProcAssets.gd` |
| Textures | Generated at runtime as seamless `NoiseTexture2D` with gradient ramps and derived normal maps | `project/autoload/ProcAssets.gd` |
| Materials | `StandardMaterial3D` and `ShaderMaterial` built in code | `project/autoload/ProcAssets.gd` |
| Shaders | Written for this project | `project/shaders/*.gdshader` |
| Sound effects | Synthesised from oscillators, noise and envelopes | `project/autoload/ProcAudio.gd` |
| Ambience | Synthesised by filtering noise into seamless loops | `project/autoload/ProcAudio.gd` |
| Music | Sequenced live from synthesised instrument one-shots | `project/autoload/ProcAudio.gd`, `project/autoload/AudioDirector.gd` |
| Concept-art gallery | Drawn procedurally per plate from a deterministic seed | `project/ui/ConceptArt.gd` |
| Application icon | Hand-written SVG | `project/icon.svg` |
| Levels | Constructed in code by the chapter scripts | `project/chapters/*.gd` |
| Writing, lore, dialogue, names | Written for this project | `project/chapters/*.gd`, `project/core/util/ChapterDB.gd`, `project/data/credits.txt` |

## Originality

The Fracture, the Veilforge Device, MOTE, the Threefold Climate Engine, the
three reality states, all eight locations, all characters, all lore and all
dialogue were created for this game. No names, plots, characters, mechanics
implementations, art or audio were taken from any existing game or franchise.

## Build tooling

Godot 4.3's official Linux editor binary and Windows export templates were used
to build the release. They are development tools, are not redistributed as part
of the game, and are covered by the same MIT licence above.
